How this answers without a server

The corpus is downloaded once and everything else happens in this page: retrieval, the gates that can refuse a question, sentence selection and the grounding check that traces every claim back to a cited passage. There is no model. The engine selects and cites stored sentences, so it cannot state anything the sources do not already say — and it cannot answer a question the corpus does not cover, which is why it sometimes tells you that instead.

A test runs every question in the published evaluation suite through both this engine and the Python pipeline the nightly grades, and fails the build if they return different verdicts, different evidence or different words. What you read here is what was graded.

Every answer is traceable to a stored source. Every knowledge area publishes its own test results, including the questions it fails.
