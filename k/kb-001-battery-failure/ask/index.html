Nothing is answering yet. This page is the interface; the engine runs where your knowledge and your model are. Start it on the machine with Ollama, then reload: 
git clone https://github.com/richardawe/knowledge-foundry
cd knowledge-foundry && pip install -e ".[dev,web]"
ollama serve &                  # llama3.1:8b
make build && make serve         # http://localhost:8000
Meanwhile, every question the system has already been asked — with the evidence behind each answer, and the ones it got wrong — is in the transcript.
