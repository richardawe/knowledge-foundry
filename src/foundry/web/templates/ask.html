Looking for a running instance…

Nothing is answering yet. This page is the interface; the engine runs where your knowledge and your model are. One command, from nothing: 
git clone https://github.com/richardawe/knowledge-foundry
cd knowledge-foundry && ./start.sh

Two processes are involved, and they are easy to confuse. ollama is the model, on port 11434 — shared with anything else you run through it. foundry serve is this application, on port 8000; it uses Ollama but is not Ollama. A running Ollama does not mean this is running, which is what the message above is reporting. ./start.sh starts the second one.

Already running it? Your instance serves this same page itself, on its own origin — no cross-origin call, nothing for a browser to block:
http://localhost:8000/k/{{ manifest.id }}/ask
That route works everywhere, including Safari.

Meanwhile, every question the system has already been asked — with the evidence behind each answer, and the ones it got wrong — is in the transcript.

Point this page at a different instance

Anything speaking this project's ask API: another machine on your network, or a tunnelled HTTPS endpoint so readers who are not running it themselves can use it too. Shareable as ?api=<url>.
